### What it is
Flowdoro is a lightweight desktop productivity application built using Tauri, HTML, CSS, and JavaScript. Pretty simple generic Pomodoro application, made to help bodo people like me to study. 

### Features
- **Customizable Pomodoro Timer**: Switch between focus and break modes and customize duration times.
- **To-do List**: Create a list of tasks and check them off. Then procrastinate and never finish it.
- **Ambient Video Player**: Load videos with a Youtube URL or from local machine. It will play automatically when you start the timer.
- **Daily Progress Tracker**: Monitor your daily goal, maintain your streak to show how lifeless you are.

### How to run
1. Ensure you have **Node.js** and the **Rust** toolchain installed.
2. In the project root, install the dependencies:
   ```powershell
   npm install
   ```
3. Run the application in Tauri's development mode:
   ```powershell
   npm run tauri dev
   ```
